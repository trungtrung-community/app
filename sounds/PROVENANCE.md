# Interface sounds — where they came from

_The product ships `P8 · About & licences`, so every asset in the bundle has to be
attributable. This file is that record for the four interface cues._

`docs/07`, 2026-08-18 admits interface sounds as a class distinct from teaching audio:
nobody imitates a UI tick, so they may be synthesised or sourced, where every word,
phrase and syllable must be a human recording.

## The clips

Sources live here as `.ogg`. They are **not** bundled — Metro's `assetExts` does not
include `ogg`, which is one of the two reasons they are transcoded at all. The shipped
files are `assets/sounds/*.wav`, generated by `scripts/build-sounds.ts`.

`notification.ogg` is bound to no cue. It is reserved for the local notification (N1/N2),
which does not go through `CuePlayer` at all — that is the `expo-notifications` config
plugin, and Android wants a `.wav` registered on a notification channel.

## Open, and blocking the beta

**The four files are dated 2020 and their licence is not established.** Their Vorbis
comment blocks carry only the encoder version, so the files themselves say nothing about
where they came from. Raised 2026-08-18 and Thosam chose to keep them; this file is the
place the answer goes when it is known.

Until then, treat the set as provisional. If the origin turns out to be unusable, the
replacement path is cheap and already isolated: drop four `.ogg` files in here, run
`npm run sync:sounds`, and re-tune the gains in `src/infra/cues/clips.ts`. Nothing in the
app names a file except that one table.

## The register they have to sit in

`docs/01`'s never-do list bans **lotus-and-incense mysticism**. It is written about
cultural notes, and a singing-bowl chime would import exactly that register through a
door the rule does not watch. A dry click — a mala bead, a prayer-wheel detent — is the
Tibetan-adjacent texture that does not. Worth holding in mind when these are replaced.
